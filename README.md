# Blender Animation Assist (BAA) プレビュー版

Blender 5.2のポーズモードで使うアニメーション補助アドオンです。既に公開しているスマートIKとチェーンモーションをこのアドオンに統合し、新機能として、PoseAssist、反対側コピー、Pivot Rotate、Rig Tweakを一度にインストールできます。

## インストール

**[Blender用ZIPをダウンロード（1.5.3）](https://github.com/IUG-NAN/Blender-Animation-Assist/releases/download/v1.5.3-preview/Blender-Animation-Assist-Preview-1.5.3.zip)**

**BAA 1.5.2以前から更新する方へ**　作業中のシーンを保存し、プリファレンスで旧BAAをアンインストールしてBlenderを再起動してください。BAAが2件ある場合は両方が対象です。その後、上のZIPをインストールします。

1.5.3以降は、上の配布ZIPとGitHubの「Code → Download ZIP」を同じインストール先に導入すると、どちらも同じBAAとして扱われます。

1. 旧版を使用中の場合はPivotやポーズ操作を確定し、プリファレンスで Pose Assist、Mirror Pose、Chain Motion、Body Pose Assist、Pivot Rotate、Rig Tweak を無効にします。
2. プリファレンスの「ディスクからインストール」でReleaseで配布しているZIPファイルをそのまま選び、Blender Animation Assist (BAA) を有効にします。設定の自動保存がオフの場合はプリファレンスを保存します。
3. アーマチュアをポーズモードにして、3Dビューのサイドバーで「BAA」を開きます。

## 使い方

### PoseAssist
- 手のIKまたはFKコントローラーを選んで「PoseAssist」を押すと、その手をIKで操作できます。
- 横に出した手を前へ回すと鎖骨・胸郭・骨盤が回旋し、上下に動かすと肩が上がり下がりします。「背骨にも配分」でチェーンモーションで登録した保存チェーンを使えます。「補助量」の「手の移動に伴う胸の回旋」で強さを調整できます。
- PoseAssist中は自動キーが有効です。もう一度押すと元の自動キー設定に戻り、開始時にFKだった手は終了フレームのポーズをFKに同期します。スマートIK移動は通常のG移動およびギズモ（Blenderのマニピュレーター）で使えます。
### スマートIK
- 手足のコントローラーでスマートIK、IK/FK切り替え、反対側コピーを使います。PoseAssistを有効にすると肩・骨盤・背骨が追従します。接地足を動かすと、左右の脚の伸びに応じて骨盤と背骨が傾き、残る伸びを骨盤の下降で補います。「補助量」の「骨盤の最大傾き」で強さの上限を調整できます。IK/FK切り替えとスマートIKには対応するリグが必要です。現状ではAutoRigProを想定した機能セットになっています。
- IK/FK切り替えは現在フレームにキーを記録し、直前の既存モードキーを一定補間にします。0Fより後で初めて切り替える場合は、元のモードを0Fに記録します。
### チェーンモーション
- チェーンモーションで選択した一連の骨（リムチェーン）を登録し、親コントローラーの回転を子に配分してキーを打つことができます。この後、必要に応じて子が遅れてついてくるラグのキーを作れます。
- 「先頭から」「末尾から」でポーズを作り、操作ボーンの回転を I または自動キーで記録すると、チェーン全体の回転が同じフレームに記録されます。
- 腕・脚のラグをキー化すると、開始から終了までを対象チェーンのFKまたはIKに固定し、途中のIK/FKキーを取り除きます。すでに作ったラグの変形キーをそのまま使う場合は、同じチェーンを選んで F3「ラグ区間のIK/FKキーを整理」から範囲を指定します。
### FreePivot
- 支点にするリグコントローラーまたはボーンを選び、右クリックの「選択中をPivotにする」で選択した対象をいつでも回転Pivotにできます。
- ギズモまたは R を使って全身を回します。「Pivot解除」で選択とピボット設定が戻り、PoseAssistは回転後の姿勢から続きます。
### 別Actionから全身ポーズを流用
- ポーズ操作パネルの「別Actionから全身ポーズを流用」で、同じリグ用のコピー元Actionとフレームを選びます。「現在Fでプレビュー」で全身を確認し、確定すると作業中のActionの現在Fに記録します。Escで取り消せます。骨盤自身の位置・回転を含めて全身をコピーします。検証リグでは c_root_master.x が対象で、それより上の c_spin、c_traj、c_pos とリグ内部の補助骨は除外します。その他のリグでは「コピーする骨盤」を指定できます。対応リグの手足は貼り付け先のIK/FKモードに同期します。
### Tweak機能
- 既存アニメーションに調整を加えるには、右クリックの「Rig Tweak」で選択骨または保存チェーンからTweakを追加します。輪にキーを打つとActionごとに調整できます。既存の輪、キー、登録済みチェーンを引き続き使えます。
- 「既存ポーズの調整」からPivotとRig Tweakを使用できます。
